尚未连接

订阅到手机日历

在一加日历的「URL 导入」中粘贴下面的链接，日历名称填写「课期」。局域网 HTTP 导入失败时，可启用 HTTPS 临时链接测试兼容性。

HTTPS 由 Cloudflare 转发只读日历，持有链接者可读取日程。免注册的临时通道重启后会更换地址，手机需重新订阅；适合先验证兼容性，长期同步需配置固定地址。

包含已同步且未完成的课表和任务。课程按上课时间显示；作业和考试只在截止日期前一天显示为「明日截止」全天日程，详情保留真实截止时间。课表覆盖当前教学周和下一教学周；平台没有提供时间的任务不会导出。手机定期刷新，更新可能有延迟。

电脑需开机并运行课期。HTTP 链接要求同一 Wi-Fi；HTTPS 链接允许手机通过流量访问。临时链接会在通道停止后失效。链接可读取你的日程，请勿转发。

手机提示无法连接？

先在手机浏览器打开链接，正常应下载 ICS 文件。若打不开，请确认同一 Wi-Fi、关闭 VPN，再双击课期文件夹内的 Enable-Calendar-LAN.bat 并确认管理员提示（只放行本地子网的 TCP 8768）。校园或访客 Wi-Fi 可能禁止设备互访，可尝试两台设备连接同一手机热点。电脑地址变化后需更新订阅链接。
