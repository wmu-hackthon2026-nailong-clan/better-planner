# 原生液态玻璃实现

参考：[rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react)，阅读版本 `ac48eab18d1f7f444ae30002d240cae29c863a21` 的 `src/index.tsx` 与 `src/shader-utils.ts`（MIT，Copyright 2025 MAX ROVENSKY）。未引入 React 或 npm 运行时依赖，C++ 材质独立实现于 `src/ui/liquid_glass.*`。

采用其背景/内容分层思路：背景先模糊，圆角边缘沿法线折射，边缘红蓝通道轻微偏移，内部文字最后绘制保持清晰；鼠标位置改变方向高光。

当前版对照优化：原示例把玻璃放在具有图像/内容细节的背景上。应用采用自主绘制的蓝青色曲线壁纸，在玻璃边缘提供可见的折射参照；侧栏改成独立悬浮面板，工具栏和概览使用 28 DIP 圆角。课表正文使用 94% 不透明浅色阅读面板，事件卡片使用类别淡色，不再逐层叠加玻璃描边。

材质保留清透中心、边缘位移蒙版、RGB 分通道偏移、方向高光及弹性交互。折射位移上限 14.4 DIP，位移在轮廓边界和中心归零，红蓝偏移为当前位移的 ±6%；饱和度按当前背景调至 115%，中心白色混合 24%，边缘下降至零。移除连续内阴影，改为方向性的细高光和柔和外阴影。胶囊按钮悬停最多位移 4 DIP、扩展 2.3 DIP，再平滑回落；未选中导航保持平面，选中导航才出现玻璃底。文字独立绘制，点击范围保持稳定。

交互定时器仅在鼠标交互后的过渡期间工作，稳定后停止；离开窗口清除悬停。关闭玻璃或启用高对比度时同时停止材质交互效果。此处是原生近似，背景采样仍限于应用装饰背景，未实现网页组件对任意底层内容的 backdrop-filter。

当前实现对应用自己绘制的曲线壁纸采样，三次半径 2 DIP 的盒式模糊近似高斯模糊，圆角 SDF 控制位移与透明覆盖。它不会采集其他窗口，也不是 Windows 系统 Acrylic；不会声称完整复刻网页 SVG 或 WebGL 管线。

玻璃应用到工具栏、侧栏、当日概览和按钮。侧栏可关闭液态玻璃；系统高对比度模式自动使用实色回退。位图按设备、尺寸、位置及材质缓存，面板缓存限制为约 32 MiB/64 项；设备重建/导出切换时释放。

离屏验收入口：`better_planner.exe --export-ui preview.png`，可附加 `--week`、`--month` 或 `--no-glass`。它使用内存中的测试课表，不连接账号服务、不修改用户课表，直接复用实际窗口的 `RenderWindowScene`，输出 1280×800 PNG；用于同尺寸改前/改后及视图回归检查。离屏预览不等同于验证真实鼠标交互。

验收：实际窗口检查亮色背景可读性、卡片边缘与圆角、鼠标高光、关闭特效、滚动裁剪、导出图片；编译通过不替代实际截图验收。

高 DPI 修复：进程启用 Per-Monitor V2，窗口响应 WM_DPICHANGED；Direct2D 目标 DPI、输入坐标及滚动范围使用一致的 DIP 换算。窗口文字使用 ClearType，按钮文字不随玻璃变形而偏移。玻璃位图按目标 DPI 的物理像素生成，并将 DPI 纳入缓存条件。离屏导出可附加 --scale-2 输出 2560×1600 的 200% 验证图。
