# 桌面登录与同步

桌面工具栏的“连接与同步”打开本机浏览器账号页：

1. 学习通输入手机号和密码，等待登录成功；可选 Windows DPAPI 加密记住密码。
2. 智慧树点击“获取登录二维码”，用知到 App 扫码并确认。
3. 分别点击“同步学习通”或“同步智慧树”。下方按数据流显示成功、失败及最近成功时间。
4. 已保存的平台日程自动回填桌面；失败不清空旧数据，相同平台/外部 ID 的记录更新而非重复追加。

学习通读取当前周/下周课表、作业、考试。智慧树覆盖共享课作业/考试和 AI 知识图谱发布任务、考试待办及知识点进度；不覆盖学校教务课表或翻转课。没有截止日期的任务保留在本机数据库，在连接页的无日期任务列表查看，不伪造日历时间。

## 首次安装

在项目根目录运行 `python scripts/setup_desktop.py`。脚本下载官方 Python 3.14.0 嵌入运行时，并安装 `prepare_connectors.py` 固定源码版本的两个连接器。已有 config.local.json 的字段保留，新字段以默认值补齐；新运行时不修改全局 Python。

运行时在 `runtime/`，连接器源码在 `.deps/`，凭据与 SQLite 数据库在 `data/`，这些目录不提交仓库。`desktop_python` 可指定其他能运行此服务的解释器。

桌面从程序所在路径查找项目根目录，隐藏启动 `python -X utf8 -u -m app.desktop_service`，服务仅监听 127.0.0.1 随机端口，避免与外部 HTTP 接口端口冲突。Windows Job Object 随桌面关闭而终止服务及登录子进程。

浏览器 POST 校验本机 Host/Origin 和随机会话 token。密码通过 POST 和子进程 stdin 传递，不进入命令行、stdout 或日志。桌面只接收日历快照及同步摘要。界面登录成功不代表后续所有平台端点一定可用；验证码、会话过期和部分接口失败仍会在同步记录中提示。

普通启动为空数据并恢复已保存的平台记录；`better_planner.exe --demo` 才加载示例数据。真实登录与扫码需用户本人完成，离线测试只验证请求路由、状态流转、去重与错误处理。

同步核对：连接页按课表/作业/考试列出最近一次读取的新增、更新、未变化、缺少日期数量，并提供课程、标题、时间、地点、教师明细。本次返回记录按标识去重；失败时不沿用上次成功的统计。报告随 sync_state 持久化，旧数据库自动增加 report 列；旧同步记录需重新同步才有明细。页面另提供本地已保存记录的按平台/课程搜索，明确包含历史数据。“可进入日历”仅表示满足日期条件，不是桌面渲染确认，也不是与平台完整课程清单核验通过。智慧树支持共享课及 AI 知识图谱任务，学习通课表范围为当前周和下周。


AI 知识图谱：scripts/zhs_ai_readonly.py 通过 queryStudentAICourseList 发现课程，使用 kg-ai-run 的 course-basic、v2/pc/get-user-tasks、v2/get-exam-todo-tasks 三个只读端点。课程列表成功字段为 status=200（兼容 code=0）；业务接口严格检查 code=200。请求复用已安装依赖的 ai_key/iv，AES-CBC PKCS7 加密课程标识，外层发送 date 时间戳。接口和字段已与 2026-11-03 的官方前端/用户抓包及账号实时响应核对，不需要保存浏览器请求头或复制会话指纹。共享课和 AI 使用独立会话；失败独立记录。

任务以 courseId/classId/task id 去重，任务列表与考试待办的同一考试仅保存一条。兼容旧适配器已知标识，迁移时保留本地完成状态。数值状态未确认的任务不会被推断为已完成。仅同步发布的任务元数据，不打开试卷、不作答、不上报学习进度；知识点总数、学习进度、掌握度仅保存到同步报告的课程概览。知识点内部未发布为任务的小测不保证覆盖。
