# 桌面登录与同步

桌面工具栏的“连接与同步”打开本机浏览器账号页：

1. 学习通输入手机号和密码，等待登录成功；可选 Windows DPAPI 加密记住密码。
2. 智慧树点击“获取登录二维码”，用知到 App 扫码并确认。
3. 分别点击“同步学习通”或“同步智慧树”。下方按数据流显示成功、失败及最近成功时间。
4. 已保存的平台日程自动回填桌面；失败不清空旧数据，相同平台/外部 ID 的记录更新而非重复追加。

学习通读取当前周/下周课表、作业、考试。智慧树当前仅覆盖知到共享课作业与考试，不能承诺学校教务课表、AI 课或翻转课。没有截止日期的任务保留在本机数据库，在连接页的无日期任务列表查看，不伪造日历时间。

## 首次安装

在项目根目录运行 `python scripts/setup_desktop.py`。脚本下载官方 Python 3.14.0 嵌入运行时，并安装 `prepare_connectors.py` 固定源码版本的两个连接器。已有 config.local.json 的字段保留，新字段以默认值补齐；新运行时不修改全局 Python。

运行时在 `runtime/`，连接器源码在 `.deps/`，凭据与 SQLite 数据库在 `data/`，这些目录不提交仓库。`desktop_python` 可指定其他能运行此服务的解释器。

桌面从程序所在路径查找项目根目录，隐藏启动 `python -X utf8 -u -m app.desktop_service`，服务仅监听 127.0.0.1 随机端口，避免与外部 HTTP 接口端口冲突。Windows Job Object 随桌面关闭而终止服务及登录子进程。

浏览器 POST 校验本机 Host/Origin 和随机会话 token。密码通过 POST 和子进程 stdin 传递，不进入命令行、stdout 或日志。桌面只接收日历快照及同步摘要。界面登录成功不代表后续所有平台端点一定可用；验证码、会话过期和部分接口失败仍会在同步记录中提示。

普通启动为空数据并恢复已保存的平台记录；`better_planner.exe --demo` 才加载示例数据。真实登录与扫码需用户本人完成，离线测试只验证请求路由、状态流转、去重与错误处理。

同步核对：连接页按课表/作业/考试列出最近一次读取的新增、更新、未变化、缺少日期数量，并提供课程、标题、时间、地点、教师明细。本次返回记录按标识去重；失败时不沿用上次成功的统计。报告随 sync_state 持久化，旧数据库自动增加 report 列；旧同步记录需重新同步才有明细。页面另提供本地已保存记录的按平台/课程搜索，明确包含历史数据。“可进入日历”仅表示满足日期条件，不是桌面渲染确认，也不是与平台完整课程清单核验通过。智慧树仍只支持共享课作业/考试，学习通课表范围为当前周和下周。
