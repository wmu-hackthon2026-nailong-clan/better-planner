# 教务系统课表抓取书签（bookmarklet）使用说明

## 这是什么

一个「书签小工具」。**书签 = 收藏夹里的一个网址**——浏览器地址栏下方那条
「书签栏」（也就是「收藏夹」）里，可以放一些网址快捷方式；点一下就跳转。
我们这个「书签」特殊之处在于：它的「网址」不是网页，而是一段 `javascript:`
开头的脚本，点它会**执行脚本**而不是跳网页。

在**已登录**的教务系统「课表查询」页面上点击这个书签，它会自动调用后台
接口，把完整课表 JSON 抓下来并下载成 `.json` 文件。之后在「更好规划」应用
里点 **「导入课表」** 选择这个文件即可。

> 为什么用书签而不是全自动？因为教务系统登录有验证码（正方/网易/顶象），
> 无法绕过。你只需像平时一样登录、进到课表页面，剩下的抓取交给书签。

## 安装书签（一次即可）

「书签」就是「收藏」。新建一个收藏，把网址填成脚本即可：

1. 打开 `timetable_bookmarklet.oneline.txt`，**全选复制**里面的内容
   （一整行，以 `javascript:` 开头）。
2. 在浏览器里新建一个「收藏/书签」：
   - **Chrome / Edge**：
     - 按 `Ctrl+Shift+B` 打开「书签栏」（就是地址栏下方那条收藏栏）；
     - 在书签栏空白处**右键** → 「添加网页」；
     - 「名称」随便填（如「抓课表」），「网址」那一栏**粘贴**（`Ctrl+V`）刚才复制的内容；
     - 保存。
   - **Firefox**：`Ctrl+Shift+B` → 右键书签栏 → 「新建书签」，同上。
3. 完成。以后点这个书签就会执行脚本。

> 找不到「添加网页」？也可以在地址栏左侧点 **☆（星星）** 收藏当前页，然后
> 在收藏夹里右键那个收藏 → 「编辑」→ 把网址改成脚本内容。

> 若浏览器把粘贴的内容截断或拒绝，检查一下粘贴进去的是不是**完整一整行**
> （开头 `javascript:`，结尾 `})();`，中间没有换行）。

## 使用步骤

1. 用浏览器登录教务系统 → 进入「课表查询」页面（能看到课表的那一页）。
2. 点击书签「抓课表」。
3. 页面会弹提示「已抓取 N 条课表」，并自动下载一个
   `课表_2026-2027_第1学期_张励志.json` 之类的文件。
4. 打开「更好规划」应用 → 点顶部 **「导入课表」** 按钮 → 「选择文件」→ 选刚下载的文件。
5. 完成，课表会展开成整学期的日程。

## 技术说明

- 接口：`POST /jwglxt/kbcx/xskbcxMobile_cxXsgrkb.html`
- 参数：`xnm`(学年)、`xqm`(学期)、`kblx`(课表类型)、`doType='app'`，
  均从页面隐藏字段 `#xnm_hide` / `#xqm_hide` / `#zs_hide` 与全局 `kblx_str`
  读取，与页面本身完全一致，无需手工填写。
- **不依赖 jQuery/Zepto**：脚本用原生 `document.getElementById` +
  `XMLHttpRequest` 发请求，避免页面库未加载或被覆盖导致
  `jQuery is not defined` 报错。
- 输出结构与「更好规划」`parseTimetable` 解析器兼容：
  `{ qsxqj, xsxx, kbList[], sjkList[] }`，其中 `kbList` 每条含
  `kcmc` / `xqj` / `zcd` / `jcs` / `cdmc` / `xm` 等字段。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `timetable_bookmarklet.js` | 源码版（可读、带注释），便于修改 |
| `timetable_bookmarklet.oneline.txt` | 单行版（直接复制到书签） |
| `build_bookmarklet.py` | 由源码版重新生成单行版 + 应用内嵌头文件的脚本 |

修改源码后运行 `python3 tools/build_bookmarklet.py`，会同时重新生成
`oneline.txt` 和 `src/ui/bookmarklet.inc`（应用内「复制书签脚本」用）。
